# UGTE ISET Bizerte — Student Guide

نسخة محسّنة من مشروع دليل الطالب الخاص بـ UGTE ISET Bizerte.

## ما تم تحسينه
- تعريف واضح بالاتحاد العام التونسي للطلبة UGTE ودوره الطلابي.
- صفحة غنية عن ISET Bizerte: التعريف، المهمة، المجالات، الاتصال، الصور والخريطة.
- Google Maps مدمج + زر مباشر لفتح المسار.
- Gallery لصور المعهد.
- إدماج صور وثائق الترسيم والسكن المرفوعة مع المشروع.
- تصميم Responsive للهاتف والكمبيوتر.
- Checklist تفاعلية محفوظة محليًا عبر localStorage.
- FAQ تفاعلية.
- تنبيه واضح بأن المعلومات الإدارية المتغيرة يجب تأكيدها من الجهة الرسمية.
- روابط للموقع الرسمي لـ ISET والمنصات ذات الصلة.

## الملفات
- `index.html` الرئيسية
- `iset.html` معلومات ISET Bizerte
- `tarsim.html` الترسيم الجامعي
- `mancha.html` المنحة
- `sakan.html` السكن الجامعي
- `assets/img/` الصور والشعار
- `assets/docs/` الوثائق المصورة التي تم رفعها
- `assets/css/style.css` التصميم
- `assets/js/main.js` التفاعلات
